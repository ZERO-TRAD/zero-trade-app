# Zero Trade

Zero Trade is a virtual trading sandbox for learners, students, and new investors to practice stocks, crypto, intraday, futures, options, and global market movement without using real money.

## Features

- ₹3,00,000 virtual starting balance
- Buy and sell simulation with a training-style dashboard
- Multi-language support: English, Hindi, Kannada
- Market cards for equities, intraday, F&O, crypto, and global assets
- Portfolio tracking and estimated virtual profit and loss
- Educational module with audio and quiz interactions
- Support/learning section with a fixed ₹23 support fee concept
- No withdrawal, no real cash in/out, and no real money investment flow

## Files

- `index.html` – app structure
- `styles.css` – trading UI styling
- `app.js` – data, market simulation, trading logic, and language support

## Run locally

Open `index.html` directly in a browser, or serve it with any static server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a front-end training prototype. It uses live crypto market data when available and falls back to realistic mock data when API access is unavailable. It is designed to feel like a live market experience but remains fully virtual, safe, and educational.
